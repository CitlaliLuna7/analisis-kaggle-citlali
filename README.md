## **Descripción**
Este proyecto consiste en el análisis, limpieza e ingeniería de datos de la base de datos **Students Performance** obtenida de Kaggle. El objetivo principal es garantizar la reproducibilidad del entorno de desarrollo y los resultados del análisis utilizando control de versiones con Git, GitHub y entornos virtuales de Python.

---

## **Estructura del Repositorio**

* `analisis_kaggle.ipynb`: Libreta de Jupyter con el análisis exploratorio y limpieza de datos.
* `datos_limpios.csv`: Dataset resultante procesado y exportado.
* `requirements.txt`: Lista de dependencias y librerías necesarias para la ejecución.
* `.gitignore`: Archivo de configuración para ignorar el entorno virtual y archivos innecesarios.
